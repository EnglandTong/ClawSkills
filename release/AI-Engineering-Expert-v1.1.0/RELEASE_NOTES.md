# AI Engineering Expert 1.1.0 Release Notes

This ClawHub bundle Plugin and Qoder Expert Kit contains:

- `cms-project-governance` 2.1.0;
- `agent-loop-engineering` 2.1.0;
- bilingual Qoder/OpenClaw/Claude routing metadata;
- read-only Legacy Bootstrap, compact state validation, and regression fixtures.

Version 1.1 directly recognizes the user's Controller-Developer-QC CMS invocation, maps QC to Stage Reviewer, performs project-local reversible work proactively, and preserves independent Standard/Full final acceptance. It also introduces Compact context and verification-cost rules instead of repeatedly reading history, replaying full logs, or running unchanged full regressions.

ClawHub distribution is a `bundle-plugin` published from `plugins/ai-engineering-expert` or its exact committed GitHub source. The Qoder ZIP remains a separate Expert Kit artifact; it should be extracted before using it as a local ClawHub source and is not a ClawPack code-plugin `.tgz`.

## 中文摘要

1.1 Plugin 同步两个 2.1 Skill，可直接理解“按 CMS 规则推进、Controller 派工、Developer 开发、QC 验收、自主解决、目录外禁止修改”的提示词。QC 映射为阶段审查；Standard/Full 仍由另一个 Agent、任务或人工做独立终验。Plugin 还包含旧项目只读引导、聚合式校验器和低 Token 执行协议。
